# A5 — payload interface fit and retention

## Question

Can the hybrid rail preserve the required external dispenser interface while retaining every
magnetic insert through ascent and deployment?

## Bands declared before drawing release

- External contact material remains hard-anodized aluminium.
- Selected provider rail width, roughness, edge radius and contact-length requirements pass.
- No insert or fastener depends on adhesive alone for ascent retention.
- Worst-case tolerance stack passes a physical fit-check fixture.
- Random vibration produces no insert movement detectable at 25 micrometres.
- A 100-cycle deployment wear test produces no rail damage or debris.

## State

NOT RUN. The CubeSat Design Specification is guidance; the selected launch-provider interface is
the controlling document once known.
